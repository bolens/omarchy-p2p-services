# Support

Start with the user guide for [installation and usage](https://bolens.github.io/omarchy-p2p-services/#guide)
or [troubleshooting](https://bolens.github.io/omarchy-p2p-services/#troubleshooting).
If the problem remains, open the matching GitHub issue form and include
plugin/Omarchy versions plus minimal reproduction steps.

Follow the guide's [privacy and diagnostics](https://bolens.github.io/omarchy-p2p-services/#privacy)
instructions when preparing a public report. Report vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/bolens/omarchy-p2p-services/security/advisories/new).

This project is maintained on a best-effort basis; response and resolution
times are not guaranteed.

# Support

Read [README.md](README.md) for installation, configuration, dependencies,
privacy behavior, and removal instructions. If the problem remains, open the
matching GitHub issue form and include plugin/Omarchy versions plus minimal
reproduction steps.

Keep private mode enabled and remove peer endpoints, credentials, usernames,
paths, and unrelated logs from public reports. Report vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/bolens/omarchy-p2p-services/security/advisories/new).

This project is maintained on a best-effort basis; response and resolution
times are not guaranteed.
